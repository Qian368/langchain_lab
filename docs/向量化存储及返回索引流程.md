# 向量化存储及返回索引流程

```mermaid
---
config:
  flowchart:
    curve: linear
---
graph TD
	subgraph SG1[文档（实际为chunk）编码及返回索引]
		direction TD
        文档+id列表 --> 文档向量化
        文档向量化 --> faiss索引集合对象
        faiss索引集合对象 <--> 持久化索引

        文档+id列表 <--> 持久化文档

        持久化索引 <--> 持久化
        持久化文档 <--> 持久化

        输入问题 --> 向量化问题
        faiss索引集合对象 -->|按 top_k 查询| 向量化问题

        向量化问题 -->|吐出| 相似度分数
        相似度分数 --> |最小阈值过滤| 结果

        向量化问题 -->|吐出| a([原文档列表索引]) 
        a([原文档列表索引])   -->|索引原列表| 结果 

        文档+id列表 -.-> a([原文档列表索引]) 

        style a fill: #1f65fadd
	end
```
